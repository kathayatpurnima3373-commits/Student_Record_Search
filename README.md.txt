# Student Record Search System

## Project Description
This project implements a Student Record Search System using three data structures in C.

## Data Structures Used
1. Binary Search Tree (BST)
2. AVL Tree
3. Hashing with Linear Probing

## Operations
- Insertion
- Searching
- In-order Traversal
- Collision Handling

## Dataset
30 unique student records.

## Programming Language
C

## Compiler
Online GDB

## Project Files
- Source_Code/bst.c
- Source_Code/avl.c
- Source_Code/hashing.c
- Output_Screenshots/
- Report/

## Conclusion
This project compares the performance of BST, AVL Tree and Hashing for student record management.
